# Car Black Box System Using PIC16F877A

## Project Overview

The Car Black Box is a microcontroller-based embedded system developed as part of the Microcontroller Module during my embedded systems training at Emertxe Information Technologies.

The project demonstrates the integration of microcontroller peripherals using Embedded C, custom peripheral drivers, and hardware interfacing.

## Hardware and Software

- Microcontroller: PIC16F877A
- Programming Language: Embedded C
- IDE: MPLAB X IDE
- Compiler: XC8
- Simulation Environment: PICSimLab, if applicable

## Key Features

- Event logging
- LCD-based menu navigation
- ADC-based analog input acquisition
- DS1307 RTC interfacing
- I2C communication
- UART-based serial communication
- EEPROM-based event storage
- Keypad-based user interaction
